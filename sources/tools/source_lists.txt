# Blog lists to harvest links from, one per line. Blank lines and # comments are
# ignored. Adding a line here is the whole of adding a source list; see
# sources/tools/README.md for how to pick a form and how to check one before
# committing it.
#
#   https://github.com/owner/repo     every list file in the repository is read
#   https://github.com/topics/name    the topic's most-starred repos, then as above
#   https://example.com/page.html     an HTML page: its links are the blogs
#   https://example.com/list.opml     a subscription list: site and feed together
#   https://example.com/list.yaml     any structured file: .yaml .json .csv .xml
#
# Prefer a structured file over a repository when a list publishes one. It names each
# blog, often gives its feed outright, and skips the rest of the repository.
