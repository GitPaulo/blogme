# Blog lists to harvest links from, one per line. Blank lines and # comments ignored.
#
# Forms, and how each is read:
#   github.com/owner/repo         every list file in the repository
#   github.com/topics/name        that topic's top repositories, then as above
#   URL ending .opml .xml         outlines: site and feed together
#   URL ending .yaml .yml .json   structured: every line is scanned for links
#              .jsonl .csv .tsv
#   URL ending .html .htm, or     anchors: the link text names the blog
#              anything unknown
#   URL ending .md .markdown      list lines only: bullets, table rows, bare URLs
#              .txt .rst
#
# Prefer a published OPML or data file over the repository holding it: it names each
# blog, often gives the feed outright, and skips the rest of the repository. See
# README.md for how to check a seed before committing it.
